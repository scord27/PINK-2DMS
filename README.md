# P.I.N.K (Peak INterpretation via picKing)

P.I.N.K is a set of 4 python scripts with GUIs for the untargeted analysis of 2DMS data based on peak picking.
<img width="800" height="400" alt="image" src="https://github.com/user-attachments/assets/64b96401-c66e-4dd5-9f71-1ca2f82cec3c" />
P.I.N.K can take the user from an initially processed surface plot (currently combatable with Touchstone .metal files and SPIKE .msh5 files) through to PCA analysis of multiple datasets or to individual MS^2^ spectra which can also undergo database searching. This can be done within the P.I.N.K workflow or at any points can be pulled out as generic formats for use with other tools.
